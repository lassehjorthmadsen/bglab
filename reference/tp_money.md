# Take points, money game

Calculate take points for money game, Janowski-style

## Usage

``` r
tp_money(probs, cube_eff = 2/3)
```

## Arguments

- probs:

  numeric vector of length 6, representing outcome probabilities (must
  always sum to 1 or 100)

- cube_eff:

  cube-life index, between 0 and 1, defaults to 2/3

## Value

double. Take point
