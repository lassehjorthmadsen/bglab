# R-package: `bglab`

This is a collection of useful functions for calculations related to
backgammon.

For example,
[`ggboard()`](https://lassehjorthmadsen.github.io/bglab/reference/ggboard.md)
creates backgammon positions using the `ggplot2` package.

Other functions calculate take points in different flavors, like
[`tp()`](https://lassehjorthmadsen.github.io/bglab/reference/tp.md) and
[`tp_gammons()`](https://lassehjorthmadsen.github.io/bglab/reference/tp_gammons.md),
or scale a certain match winning probability to equivalent-to-moneygame,
[`emg()`](https://lassehjorthmadsen.github.io/bglab/reference/emg.md),
in the same way as programs like [eXtreme
Gammon](https://www.extremegammon.com/) does.

See the function
[references](https://lassehjorthmadsen.github.io/bglab/reference/index.html)
for a full overview.
